How to

使い方

  1. DXF を選ぶ「DXF を選ぶ」を押すか、ファイルをドラッグします。
    Shift_JIS の DXF も UTF-8 の DXF も読めます。ファイルはどこにも送りません。
  2. 縮尺と単位を入れる縮尺（1/100 なら 100）と、図面の単位（mm など）を入れると、長さがメートルに直ります。
  3. 表を見て、CSV で保存画層ごとの表と、ブロックの名前ごとの表を、CSV で保存できます。Excel で開けます。

Count

数える物と、数え方

数える物と数え方
図形数え方
線（LINE）画層ごとに、本数と長さの合計を出します。
ポリライン（LWPOLYLINE・POLYLINE）画層ごとに、本数と長さの合計を出します。円弧のふくらみ（バルジ）も、弧の長さで数えます。閉じたポリラインは、最後の辺も入れます。
円（CIRCLE）・円弧（ARC）画層ごとに、個数を出します。
ブロック（INSERT）ブロックの名前ごとに、挿入された個数を出します。どの画層に何個あるかの内訳もつけます。
文字（TEXT・MTEXT）画層ごとに、個数を出します。
数えない物ハッチ・寸法・スプライン・楕円・ブロックの定義の中の図形です。数えなかった図形は、種類と個数を表の下に出します。

DXF の中の図形は、ENTITIES（図面の本体）にあるものだけを数えます。

Notes

使うときの注意

  • 同じ場所に重なった線は、そのまま二重に数えます。
  • 縮尺や単位をまちがえると、長さが桁ちがいになります。部屋の幅など、寸法のわかる線で、一度見くらべてください。
  • 出るのは、線の長さと図形の個数だけです。面積・体積、控除（開口部を引くこと）、仕上げの種類ごとの区分は出しません。
  • 数えた結果は、原図と見くらべてお使いください。

FAQ

よくある質問

DXF のファイルは、どこかに送られますか？

送りません。
ファイルは、お使いのブラウザの中だけで読んで数えます。
サーバーには何も送りません。

どんな DXF を読めますか？

ASCII 形式（文字の形式）の DXF です。Shift_JIS の DXF も UTF-8 の DXF も読めます。
バイナリ形式の DXF と DWG は読めません。CAD で ASCII 形式の DXF に保存し直してください。

縮尺と単位は、どう入れますか？

実寸（1 : 1）で描いた図面は、縮尺に 1 を入れます。
用紙の寸法で描いた 1/100 の図面は、100 を入れます。
単位は、mm で描いた図面なら mm です。DXF に単位が書いてあれば、最初から選んであります。
どちらか分からないときは、図面の中のわかっている寸法（部屋の幅など）の線を拾って、長さを見くらべてください。

面積や体積は出ますか？

出しません。この道具が出すのは、線・ポリラインの長さ、円・円弧・ブロック・文字の数です。
部屋ごとの面積や、壁・天井の仕上げの数量は、拾いの代行でお受けします。

同じ場所に線が重なっていると、どうなりますか？

そのまま二重に数えます。重なった線を一本にまとめる処理は、していません。
結果は、原図と見くらべてお使いください。

ブロックの中の線や文字は数えますか？

数えません。ブロックは、挿入された個数を、名前ごとに出します。

料金はかかりますか？

無料です。登録もいりません。
数量を拾う作業そのものを頼みたいときは、積算・数量拾いの外注（お見積り無料）をご覧ください。
